#+title: How-to: gptel
#+filetags: :howto:dotfiles:
#+aliases: "GPTel" "Useful gptel workflows"

gptel works from ordinary code, prose, Org, and Markdown buffers. The shortest
paths cover most daily use; the complete command map is under =SPC o l= and is
also available without Doom's leader as =C-c l=.

* Rewrite a selection

Select code or prose in Evil visual mode, press =SPC r=, and describe the
change. The completed response replaces the selection automatically as one undo
step.

#+begin_example
This paragraph have too many words and it do not explain the idea clearly.
#+end_example

For example, select that sentence, press =SPC r=, and ask: “Make this concise
and grammatical.” Press =u= to reject the applied rewrite, or =C-r= to restore
it. Use =SPC o l R= instead when you want the review-first overlay before
accepting a change.

* Explain something quickly

Put point on an identifier or select a region and press =SPC o l e=. The answer
appears in a small popup:

- =+= asks for a longer answer.
- =w= copies the answer.
- =r= carries the question and answer into a chat buffer for follow-up.

When LM Studio is running, quick explanations use the local Qwen3.6 MLX model
also offered to Pi. Otherwise
they fall back to the current session backend.

* Use a project agent

Run =pi= in a terminal from the project root when the job needs repository
exploration, edits, commands, or a long-lived agent session.

In Emacs, use =SPC o l l= for an ordinary gptel chat,
=SPC o l A= for a gptel-agent buffer, and =SPC o l F= when you explicitly want
to attach project files to the current gptel conversation. The older persistent
gptel project helper remains available as =M-x my/gptel-project= for existing
=.gptel/chat.org= transcripts, but has no keybinding.

* Choose where the request runs

=SPC o l b= toggles between the private layer's primary provider and local
LM Studio/MLX, keeping the appropriate model for each backend. =SPC o l m= opens
gptel's menu for choosing a model, preset, tools, context, or response
destination.

Treat context as part of the request: selected regions and files are sent to
the active backend. For private or work material, use only a backend permitted
for that data. Local LM Studio keeps the model request on the machine, although an agent can
still make external requests when you allow it to use web tools.

* Small useful extras

- In a Magit commit-message buffer, =M-g= drafts a commit message.
- =SPC o l a= adds or removes the current region or buffer as live context.
- =SPC o l f= adds a specific file as context.
- The entire =SPC o l= map is mirrored under =C-c l=.
